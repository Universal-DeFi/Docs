When you redeem a commodity token for the physical metal, it ships to your primary delivery address. You only need a delivery address if you plan to take physical delivery.

## Add an address

1. In your **Personal** workspace, select **Delivery addresses** under **Account**.
2. Select **Add address** and enter the address.
3. Select **Set as primary** on the address you want redemptions shipped to.

## Change or remove an address

Select **Remove** to delete an address. A redemption already on its way keeps the address it was dispatched to.

## Organization addresses

Redemptions filed in an organization's name ship to the organization's own addresses. Manage those on the organization's **Organization** page.

<Tip>
  If a redemption form shows **No delivery address on file**, add one here, then return to the request.
</Tip>
